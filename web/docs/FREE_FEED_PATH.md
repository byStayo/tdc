# Free feed access and alternatives

Verified November 3, 2026. This guide distinguishes access research from verified integrations. The product remains free to readers and this plan requires no paid feed or paid model API. Fed private-credit collection and presentation are implemented; see the build ledger for release verification. Other new candidates below remain unintegrated unless explicitly recorded there.

## FINRA: the only immediate owner setup

Follow [FINRA_SETUP.md](FINRA_SETUP.md): Individual account, activated Public credential ($0/month), then the hidden-input local setup command. The local publisher can use that file without retrieving Vercel Secrets. Real access still needs private verification. FINRA's equity terms allow conditional free redistribution, not an unrestricted Git/download archive. Weekly ATS/non-ATS volume is delayed activity, not known buying or selling intent.

## Concrete private-credit addition

The Fed table S124.8.t adds genuinely new information beyond the existing old SEC private-equity asset levels. Relevant series include private-credit loan net acquisition (`FA443067205`), total financial-asset acquisition (`FA444090000`) and net share issues (`FA443164500`). The latest table is 2026 Q2, released September 11, 2026. Quarterly flow units are **billions of dollars at a seasonally adjusted annual rate**. A 50.0 loan-flow figure does not mean $50bn cash moved within that quarter. The dated release says underlying private-debt inputs run only through 2026 Q1, so later values are estimates. See the [dated release](https://www.federalreserve.gov/releases/z1/20260911/z1.pdf) and [Fed methodology note](https://www.federalreserve.gov/econres/notes/feds-notes/introducing-private-credit-into-the-financial-accounts-of-the-united-states-20261016.html).

Implementation should preserve vintage, observation period, release date, units, estimated status and revisions. Add a separate context signal; do not silently turn the missing private-equity-flow input into an available daily directional vote. Do not overwrite earlier editions.

The implemented collector cross-checks the current and dated release tables, stores the dated table hash, and requires an explicitly reviewed release before using its units and input lag. It excludes annual columns, rejects missing/conflicting quarterly cells, preserves negative and zero values, and never casts a directional vote. The existing private-capital panel shows six quarter bars with the estimated quarter hatched and keeps the old SEC asset stock in a separate disclosure. Its normal publication path and scoped collection command both preserve prior immutable editions.

## Why another free API key is not enough

Alpaca's redistribution restriction rules out simply plugging its free feed into public downloads. Tiingo's [October 2026 terms](https://app.tiingo.com/tos/) prohibit persistent storage on Starter even for derived products, so that plan does not fit immutable consensus history. StockData.org's [terms](https://www.stockdata.org/tos) do not establish public redistribution. A successful HTTP response, free personal plan, existing subscription or hosted chart is not proof of public archive/model permission. This review found no provider that closes all those requirements for zero cost; it does not assert that no such arrangement could ever exist.

## Implementation order and acceptance

1. Owner completes the precise FINRA setup; Codex verifies it privately, then builds the separate conditional display boundary. No public FINRA export.
2. Add the no-key Fed private-credit context with source/date/units tests and actual rendered verification. Extend declared SEC/issuer coverage without presenting guidance as analyst estimates.
3. Add a separately labelled Bluesky sample using the verified stream, bounded collection, deletion/report handling and an explicit sampling/classification method. It must remain distinct from X and Instagram. No raw social corpus in immutable public archives.
4. Add permitted hosted FX-positioning context with original provider attribution and on-demand loading, following the existing sandbox approach. PredictionMarketsPicks public publishing is blocked by its Enterprise-key requirement despite free previews. Do not read hosted frame data into the model.
5. Keep exact US price/options, X/Instagram-wide, analyst-consensus and daily PE-flow requirements open unless specific public-use permission is supplied or the user explicitly narrows them. A free product can contain strong context without claiming every signal or a calibrated trading edge.

Future real outcomes and model qualification still take actual permitted data and prospective observations. Adding a feed does not manufacture an overnight track record.

## Research method and limits

Three internal read-only research agents covered price/options, social/retail and analyst/capital sources; Codex cross-checked decisive primary documentation, FINRA activation/fees, current Vercel Secret behavior and new prediction-source conflicts. No external Grok/Gemini execution or numerical model-vote confidence is claimed. Provider terms, not model agreement, determine the documented reuse boundary. Research did not create accounts, accept agreements, buy credits, send outreach or change production. New source findings are not deployed integrations.
