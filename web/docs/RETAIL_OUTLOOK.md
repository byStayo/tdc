# Hosted FX community outlook

The [official Myfxbook widget generator](https://www.myfxbook.com/get-widget/15/toolbar_widgets) supplies the Simple Outlook view for EUR/USD, GBP/USD, USD/JPY, USD/CAD, AUD/USD and USD/CHF. The original script configuration and Powered by Myfxbook attribution are preserved. These are selected Myfxbook community positions, not US ETF positioning or a representative sample of all retail investors. The provider controls the display, availability, timing and privacy. No source observation time is inferred from our page-load time.

The view is inside the collapsed **Community & retail** research section. A reader must choose **Load Myfxbook view** before a third-party request occurs. Closing the view or the research section removes the frame. Historical editions show a current-only notice and make no provider request; returning to the latest edition requires another load action.

Provider scripts run only in an opaque sandboxed wrapper. The wrapper permits scripts and source-link popups, not same-origin access, forms or top-level navigation. Its content security policy limits external resources to the provider domains and binds the one local bootstrap by hash. The parent accepts only ready/error status from its own opaque frame. Ready means the official display frame was inserted, not that values were independently validated or are current. The parent never reads provider positions or other frame content. A bounded failure state retains a direct source link.

The wrapper has a fixed six-pair configuration and rejects query parameters; it is not a proxy or an arbitrary URL loader. The generated third-party frame is sized for these six rows without altering its content. No provider scripts or frames are loaded on the initial homepage.

This is hosted display permission, not a raw-data archive/model licence. Provider data does not enter Git, consensus votes, coverage, saved editions, outcome scoring or training. UI verification screenshots are private design evidence, not data inputs. The full retail and social-feed requirements remain incomplete.

Live Jev decisions: `jev-retail-request.json` and `jev-retail-decisions.json`. Real browser evidence and design review: `.design/retail-outlook/`. Exact release status belongs in the root build ledger.
