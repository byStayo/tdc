# Monthly analyst-rating coverage

Quantisnow publishes its Analyst Sentiment Index as a no-key monthly dataset under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The specific [dataset grant](https://www.quantisnow.com/data/analyst-ratings) and [data-hub documentation](https://www.quantisnow.com/docs/market-data-hub) cover these aggregates. They do not extend to the provider's personal-use news/webhook products or third-party article bodies.

The November6 JSON was retrieved normally with HTTP200. Its source update is November6 06:15:37UTC. It contains65months beginningJuly2021. October's full-month sample has263upgrades,295downgrades,559initiations and101reiterations (1,218actions). November's incomplete sample has66upgrades,98downgrades,31initiations and8reiterations (203actions). These counts concern stocks captured by this provider; they do not measure all analyst activity.

`npm run consensus:analysts` collects only this source. Add `-- --publish` only after reviewing a meaningful new observation. Full collection includes the same signal in a stable position before Taiwan/private-credit context. Retrieval timestamps alone cannot create an edition. Source hashes, provider update time and retrieval time are retained. Future dates, licence changes, inconsistent totals, duplicate months, broken sector reconciliation and malformed ratios fail closed. Transport-only failures can retain the last verified observation with its original dates and ordinary stale limits.

When the JSON endpoint returns an explicitly marked Cloudflare access challenge, both collectors check Quantisnow’s CSV download. The CSV supplies monthly counts and ratios. The collector validates every row and compares every published chart point and metric with the previous JSON observation. An exact match retains that observation, its original JSON hash and both timestamps. Its seven-day freshness window continues to run from the original provider update. New or changed figures require the JSON’s sector breakdown, update time and dataset licence. An ordinary access denial or an unconfirmed CSV leaves the signal unavailable. [Quantisnow CSV](https://www.quantisnow.com/data/analyst-ratings.csv)

If the current edition recorded an outage, the collector verifies the immutable archive index against the current edition and checks the newest previously accepted observation. Recovery requires its original JSON provenance, a matching CSV and an observation still within the seven-day freshness window.

The existing signal inspector presents the new source without a new layout. Its chart uses **closed months only** and plots upgrades divided by upgrades plus downgrades, expressed as a percentage. The latest two complete months' counts and the current partial month's counts are separate metrics. No partial month is compared with a complete month. Provider zero-denominator ratio sentinels are checked but never interpreted as a negative forecast. Initiations/reiterations are not silently treated as upgrades.

Scope is **MARKET only**, with no directional vote on any horizon. Individual ETF holdings and weights are not mapped by this aggregate. Per-company estimate/target revisions and matched earnings expectations remain gaps. This is a rating-action sample, not an EPS consensus feed, validated sentiment score or measured return forecast. History reconstructed from the current download is latest-vintage context; it is not an as-issued prediction archive or model-performance record.

Attribution names Quantisnow, links the dataset and CC licence, identifies our selection/ratio calculation, and makes no endorsement claim. Raw news content, private accounts and FINRA credentials are not involved. The source requires no signup, payment or API key. Production status belongs in the root release ledger, not this implementation description.

The attributed test fixture selects the September–November2026 records from the source download; those selected records are unchanged and the original licence/citation metadata is retained. Deliberately inconsistent test variants exercise rejection and are never published as observations.

## Prospective SPY test of daily rating changes

The ordinary weekday collector retains each verified Quantisnow JSON under its content hash in the owner-only price and research workspace. The source publishes cumulative monthly rating counts and recomputes them daily. The study compares two adjacent full trading mornings in the same calendar month. Both observations must match their native responses and their publicly witnessed editions. A missed release, a decrease in any of the cumulative counts, a month rollover, a closure or an interval with no added upgrades or downgrades leaves the target pending. [Dataset and CC BY 4.0 attribution](https://www.quantisnow.com/data/analyst-ratings)

For SPY, the fixed hypothesis is that a higher balance of upgrades among the added upgrades and downgrades forecasts a positive regular-session return. The first control uses the preceding morning's cumulative balance. The other two use the training-set frequency and a constant 50 percent. Differences in provider counts may include corrections. The study makes no claim about a particular company's rating or SPY's holdings. It admits new releases after registration, protects the existing holdouts and uses 300 training, 100 validation and 100 sealed test sessions. Qualifying results require positive incremental value against every control. The live vote is separate. [Registered policy](../lib/consensus/analyst-study-policy.ts)

Run `npm run consensus:analyst-study -- --status` from `web` for the working cohort counts. The public pre-open verifier records eligible inputs and the ordinary evaluator admits the first independently verified SPY settlement. Run `npm run consensus:analyst-study -- --register` once on an authorized publishing host.
