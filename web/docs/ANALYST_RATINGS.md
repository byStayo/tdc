# Monthly analyst-rating coverage

Quantisnow publishes its Analyst Sentiment Index as a no-key monthly dataset under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The specific [dataset grant](https://www.quantisnow.com/data/analyst-ratings) and [data-hub documentation](https://www.quantisnow.com/docs/market-data-hub) cover these aggregates. They do not extend to the provider's personal-use news/webhook products or third-party article bodies.

The November6 JSON was retrieved normally with HTTP200. Its source update is November6 06:15:37UTC. It contains65months beginningJuly2021. October's full-month sample has263upgrades,295downgrades,559initiations and101reiterations (1,218actions). November's incomplete sample has66upgrades,98downgrades,31initiations and8reiterations (203actions). These counts concern stocks captured by this provider; they do not measure all analyst activity.

`npm run consensus:analysts` collects only this source. Add `-- --publish` only after reviewing a meaningful new observation. Full collection includes the same signal in a stable position before Taiwan/private-credit context. Retrieval timestamps alone cannot create an edition. Source hashes, provider update time and retrieval time are retained. Future dates, licence changes, inconsistent totals, duplicate months, broken sector reconciliation and malformed ratios fail closed. Transport-only failures can retain the last verified observation with its original dates and ordinary stale limits.

The existing signal inspector presents the new source without a new layout. Its chart uses **closed months only** and plots upgrades divided by upgrades plus downgrades, expressed as a percentage. The latest two complete months' counts and the current partial month's counts are separate metrics. No partial month is compared with a complete month. Provider zero-denominator ratio sentinels are checked but never interpreted as a negative forecast. Initiations/reiterations are not silently treated as upgrades.

Scope is **MARKET only**, with no directional vote on any horizon. Individual ETF holdings and weights are not mapped by this aggregate. Per-company estimate/target revisions and matched earnings expectations remain gaps. This is a rating-action sample, not an EPS consensus feed, validated sentiment score or measured return forecast. History reconstructed from the current download is latest-vintage context; it is not an as-issued prediction archive or model-performance record.

Attribution names Quantisnow, links the dataset and CC licence, identifies our selection/ratio calculation, and makes no endorsement claim. Raw news content, private accounts and FINRA credentials are not involved. The source requires no signup, payment or API key. Production status belongs in the root release ledger, not this implementation description.
